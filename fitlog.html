● SECTION B — PROJECT OVERVIEW

Built for Gym Consistency and Laser Focus

FitLog is a modern fitness web application crafted to streamline workout discovery, training session organization, and routine tracking. Designed specifically for active lifters and gym-goers who value speed, simplicity, and visual clarity, FitLog eliminates the unnecessary friction commonly found in mainstream fitness software.

Rather than burdening users with multi-step onboarding surveys, paywalls, or cluttered social feeds, FitLog presents an immediate, responsive gym companion: users can browse an organized exercise library across all major muscle groups, inspect target execution metrics, lock exercises into their personal daily training plan ("My Plan"), and monitor their session's progress in real time.

● SECTION C — PROBLEM STATEMENT

The Friction of Cluttered Fitness Utilities

Most commercial fitness and gym-logging mobile applications suffer from three common practical flaws:

  • Over-engineered sign-up flows: Users are forced through intrusive personal data questionnaires and subscription paywalls before they can even review an exercise.
  • Heavy, slow client interfaces: Bloated frameworks and third-party trackers slow down screen transitions during active rest intervals between sets.
  • Poor gym-floor usability: Bright white interfaces cause excessive glare in dim workout studios and drain mobile battery rapidly during extended training sessions.

FitLog addresses these practical issues directly by prioritizing instant client-side responsiveness, dark-mode ergonomics, and zero-distraction routine builders.

● SECTION H — TECHNICAL IMPLEMENTATION

Next.js 16 & React 19 Architecture

Inspection of the codebase confirms the following technology choices and architectural standards:

  • Next.js 16 (App Router): Leverages modern server-rendered shells with client components mounted where user interaction is mandatory (sorting, planner toggles).
  • React 19: Utilizes React 19 hooks and optimistic updates for instantaneous plan counter updates when locking in lifts.
  • TypeScript 5: Strict interface contracts defined for workout items (id, name, muscleGroup, duration, sets, image, difficulty).
  • Tailwind CSS 4: Latest generation Tailwind engine for high-speed style computation, custom neon utility classes, and zero CSS runtime overhead.
  • Lucide React Icons: Vector iconography tailored for fitness metrics (dumbbell, timer, calendar, heart rate).
  • Vercel Edge Network: Hosted with global asset caching, achieving lightning-fast initial content loads.
● SECTION I — RESPONSIVE DESIGN

Mobile Gym-Floor to Desktop Workstation

FitLog adapts dynamically across screen viewports:

  • Mobile Viewport (< 640px): Single-column card layout with large 48px touch targets, sticky bottom action bar, and full-width exercise previews.
  • Tablet Viewport (640px – 1024px): Two-column grid with side-by-side metric badges and collapsible filter toggles.
  • Desktop Viewport (> 1024px): Expanded multi-column library, persistent header metrics pill, and rich hover overlays.
● SECTION J — CHALLENGES & SOLUTIONS

Engineering Decisions Under the Hood

Challenge: Maintaining Instant Client Interactivity Without Heavy External Libraries.
Many routine trackers bundle heavy state management libraries like Redux or complex backend databases, introducing significant bundle overhead.

Solution: FitLog uses React 19's native state primitives with modular custom hooks, keeping the client bundle ultra-lean (< 75KB compressed) while providing instant feedback when toggling plan items.

Challenge: Image Loading Performance on Cellular Gym Networks.
High-resolution exercise renders can cause noticeable layout shift on patchy gym Wi-Fi or cellular connections.

Solution: Configured Next.js image optimization with explicit aspect ratio bounding boxes and priority loading for above-the-fold exercise cards.

● SECTION K — OUTCOME & LEARNING

Key Engineering Takeaways

FitLog demonstrated the power of deliberate restraint in digital product design: by stripping away intrusive telemetry, ads, and convoluted sign-up barriers, the user experience becomes fluid, delightful, and immediate.

Building with Next.js 16 and Tailwind CSS 4 reinforced modern web standards: lightning-quick builds, clean declarative component boundaries, and high-performance dark mode interfaces that stand out in any professional web developer portfolio.
